# Contributing

This is a solo research project. External contributions are not
currently accepted.

## Issues

If you find a bug in the code, please open an issue with:
- A description of the problem
- The exact command that reproduces it
- The full traceback

## Reproducibility

If you are attempting to reproduce the analysis and encounter a
difference from the published results, please include:
- The exact versions from your `conda list` output
- Any warnings or errors from the scripts
- Your operating system and Python version

## Code of conduct

Standard scientific norms: be precise, be honest, and document what
you cannot explain.
